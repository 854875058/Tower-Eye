# Tower-Eye / 铁塔多模态检索与智能分析平台

面向铁塔视联告警、多模态检索、智能体分析和数据工作台场景的前后端一体化项目。

当前仓库已经沉淀了以下几条核心能力链：

- 多模态数据接入：文档、表格、图片、视频、压缩包、本地路径、SFTP
- 多模态检索：文本检索、图搜图、视频片段检索、证据聚合展示
- 智能分析：运营分析问答、风险评分、处置优先级、建议动作输出
- 本体与图谱：本体配置、知识图谱展示、事件级血缘链路
- 数据工作台：采集、订阅、处理、导出、向量化、样本沉淀
- 智能标注：图片自动标注、视频跟踪标注、YOLO 标签导出

这不是一个只做上传下载的管理后台，而是一个围绕“多模态数据 -> 知识化组织 -> 智能检索与分析 -> 处置建议”构建的平台型项目。

## 1. 项目定位

当前项目主要用于承载以下三类能力建设：

1. 多模态检索能力
   支撑文本、图片、视频、结构化元数据的统一检索、关联和证据展示。

2. 智能分析与智能体能力
   面向运营分析、告警分析、异常定位、趋势展示和处置建议生成。

3. 数据工作台与模型数据底座能力
   支撑数据接入、清洗、标签抽取、聚类、订阅采集、训练样本沉淀与回流。

## 2. 当前主要功能

### 2.1 视联告警智能分析平台

页面：`/tower-demo`

已实现能力：

- 告警事件、图片、视频、设备元数据统一接入
- 区域热点分析、设备热点分析
- 低置信度事件筛查
- 区域风险分、设备风险分、事件风险分
- 处置优先队列与建议动作输出
- 智能体式分析问答
- 本体配置中心
- 知识图谱展示
- 事件级全链路血缘展示
- 页面内图片/视频预览

适合用于对外演示以下能力：

- 多模态证据检索
- 智能体分析
- 本体/图谱/血缘
- 风险排序与处置建议

### 2.2 数据工作台

页面：`/workbench`

已实现能力：

- 本地上传、本地路径、SFTP 采集
- ZIP 解包
- 文档/表格/文本/图片/视频入库
- 文本分块、向量化、标签抽取、摘要生成
- 数据集详情、语义检索、导出、删除
- 订阅创建、启停、手动执行、定时轮询
- 数据处理：清洗归一化、标签抽取、聚类、质量评分
- 导入视联告警样本数据到工作台

### 2.3 多模态查询

页面：`/query`

已实现能力：

- 文本查询
- 基于 DuckDB 的结构化查询执行
- 多模态检索结果返回
- 证据卡片、结果表格、图表建议
- 流式查询反馈
- 历史记录与回放

### 2.4 智能标注

页面：`/annotation`

已实现能力：

- 图片自动检测与标注修正
- 视频跟踪预览
- 标注会话恢复
- YOLO 标签导出
- 自动框 / 手工框切换

## 6. 运行准备

### 6.1 环境要求

- Python 3.10+
- Node.js 18+
- npm 9+

### 6.2 后端配置

复制配置模板：

```bash
cp backend/.env.example backend/.env
```

需要重点配置的变量：

- `SECRET_KEY`
- `LLM_BASE_URL`
- `LLM_API_KEY`
- `LLM_MODEL`

如果需要启用更完整的远程多模态能力，还可以补充：

- `VL_BASE_URL`
- `VL_API_KEY`
- `VL_MODEL`
- `EMBEDDING_QWEN_API_URL`
- `RERANKER_API_URL`
- `ANNOTATION_YOLO_MODEL_PATH`

## 7. 本地启动

### 7.1 后端

```bash
cd backend
python -m pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 50805 --reload
```

### 7.2 前端

```bash
cd frontend
npm install
npm run dev -- --host 0.0.0.0 --port 50803
```

### 7.3 访问地址

- 前端：`http://127.0.0.1:50803`
- 后端健康检查：`http://127.0.0.1:50805/health`

## 8. 推荐演示路径

如果当前目标是演示平台能力，建议按下面顺序操作：

1. 打开 `/tower-demo`
   先看概览、热点区域、热点设备、风险评分和处置优先队列。

2. 在智能体区域提问
   例如：
   - 当前告警在地区的分布情况
   - 哪些设备需要优先排查
   - 最近异常趋势怎么样

3. 查看图谱与血缘
   演示本体配置、知识图谱、事件血缘链和节点联动。

4. 打开 `/workbench`
   展示数据采集、向量化、订阅、数据处理能力。

5. 打开 `/annotation`
   展示自动标注和人工修正能力。
